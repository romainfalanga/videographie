# Guide Utilisateur — Vidéographie

## Préparer ton Google Drive

### 1. Créer la structure de dossiers

À la racine de ton Google Drive, crée un dossier nommé **`vidéographie`** (avec l'accent).

Dans ce dossier, crée exactement trois sous-dossiers :

```
vidéographie/
├── matière/        → Disciplines, domaines de savoir
├── mécanisme/      → Processus, fonctionnements, systèmes
└── galaxie/        → Projets, univers personnels
```

### 2. Créer des sujets

Dans chaque catégorie, crée un sous-dossier par sujet. Le nom du dossier est le nom du sujet.

```
vidéographie/
├── matière/
│   ├── philosophie/
│   ├── psychologie/
│   └── économie/
├── mécanisme/
│   ├── habitudes/
│   └── créativité/
└── galaxie/
    ├── projet-livre/
    └── voyage-japon/
```

### 3. Déposer tes vidéos

Place tes fichiers vidéo dans les dossiers-sujets correspondants.

### 4. Nommer tes vidéos

Utilise ce format pour tes noms de fichiers :

```
YYYYMMDD_HHMMSS Titre libre.mp4
```

**Exemples :**
- `20260206_134634 Atelier musique IA dans les GEM.mp4`
- `20260115_091200 Réflexion sur le temps.mp4`

Le format permet un tri chronologique automatique. Si un fichier ne suit pas ce format, l'application utilisera la date de création du fichier comme date.

## Utiliser Vidéographie

1. Ouvre l'application dans ton navigateur
2. Clique sur **« Se connecter avec Google »**
3. Autorise l'accès en lecture à ton Google Drive
4. L'application synchronise automatiquement ton dossier `vidéographie`
5. Navigue par catégorie, par sujet ou par chronologie

### Navigation

- **Accueil** : les trois catégories (matière, mécanisme, galaxie)
- **Catégorie** : les sujets de cette catégorie
- **Sujet** : les vidéos de ce sujet, triées de la plus récente à la plus ancienne
- **Chronologie** : toutes les vidéos, toutes catégories confondues, par date

### Actualiser

Clique sur le bouton d'actualisation dans la barre de navigation pour re-synchroniser avec ton Drive après avoir ajouté ou modifié des vidéos.
